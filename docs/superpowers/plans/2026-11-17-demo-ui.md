# 本地演示页（demo UI）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 提供一个本地静态网页，浏览器打开即可看到 anvil 链上拍卖状态，并完成「创建拍卖 → 出价 → 结算 → 提取」的完整演示。

**Architecture:** 单页应用，浏览器原生 ESM 加载本地 vendor 的 ethers v6 UMD。纯计算逻辑放在 `demo/lib.mjs`（零依赖，用 Node 内置 `node:test` 单测）；DOM 渲染与链交互放在 `demo/app.mjs`（用浏览器验证）。地址从仓库根目录的 `deployments/local.json` 读取，读不到则页面提供手填入口。

**Tech Stack:** 静态 HTML、浏览器 ESM、ethers 6.13.4（UMD，本地 vendor）、`node:test`、`python3 -m http.server`

**Spec:** `docs/superpowers/specs/2026-11-17-demo-ui-design.md`

## Global Constraints

- ethers 版本固定 `6.13.4`，文件 `demo/ethers.umd.min.js` 必须本地存在，页面**不得**引用 CDN
- 只连接 `http://127.0.0.1:8545`，chainId `31337`
- 不引入任何 npm 依赖与构建步骤；单测只用 `node --test`
- USD 金额一律 8 位小数（`1000` 美元 = `100000000000n`）；ERC20 金额按其 `decimals()`
- 页面文案用中文
- anvil 私钥仅用于构造内存中的 `Wallet`，不得写入日志或发起任何网络传输
- 不改动 `src/`、`test/`、`script/` 下任何文件

## Review Focus

1. **链未启动 / 合约未部署时打开页面**：应显示可读的错误提示（例如「无法连接 127.0.0.1:8545」），而不是白屏或未捕获异常。
2. **金额输入非法**（空、负数、超过两位小数、非数字）：应在前端拒绝并提示，不发出交易。
3. **推进时间后未刷新预言机就出价**：交易 revert，卡片内应显示 `StalePrice` 之类的原始 revert 原因，而不是静默失败。
4. **代理已升级到 V2**：页面仍能正常渲染，头部版本号显示 `NFTAuction V2`，不因 ABI 差异报错。
5. **账户没有待提取余额时点提取**：按钮置灰，不发空交易。

### Task 1: 纯计算库与单元测试

**Files:**
- Create: `demo/lib.mjs`
- Test: `demo/lib.test.mjs`

**Interfaces:**
- Consumes: 无
- Produces:
  - `formatUsd8(v: bigint) -> string` — 8 位小数转 `"4,000.00"` 形态（`Intl.NumberFormat('en-US', { minimumFractionDigits: 2 })`）
  - `parseUsdTo8(input: string) -> bigint` — 美元字符串转 8 位小数，非法输入 `throw new Error('金额格式不正确')`
  - `remainingSeconds(endTime: bigint, nowSec: number) -> number` — 差值，最小为 0
  - `formatDuration(sec: number) -> string` — `0` 返回 `"已结束"`；`< 3600` 返回 `"MM:SS"`；否则 `"H:MM:SS"`
  - `shortAddr(a: string) -> string` — `0xf39F…2266`

- [ ] **Step 1: 写失败的测试**

```js
// demo/lib.test.mjs
import test from 'node:test';
import assert from 'node:assert/strict';
import { formatUsd8, parseUsdTo8, remainingSeconds, formatDuration, shortAddr } from './lib.mjs';

test('formatUsd8 转美元字符串并千分位', () => {
  assert.equal(formatUsd8(400000000000n), '4,000.00');
  assert.equal(formatUsd8(100000000n), '1.00');
  assert.equal(formatUsd8(0n), '0.00');
});

test('parseUsdTo8 接受整数与两位小数', () => {
  assert.equal(parseUsdTo8('1000'), 100000000000n);
  assert.equal(parseUsdTo8('1000.5'), 100050000000n);
  assert.equal(parseUsdTo8('0.01'), 1000000n);
});

test('parseUsdTo8 拒绝空值、负数、非数字、超过两位小数', () => {
  assert.throws(() => parseUsdTo8(''), /金额格式不正确/);
  assert.throws(() => parseUsdTo8('-1'), /金额格式不正确/);
  assert.throws(() => parseUsdTo8('abc'), /金额格式不正确/);
  assert.throws(() => parseUsdTo8('1.234'), /金额格式不正确/);
});

test('remainingSeconds 不为负', () => {
  assert.equal(remainingSeconds(2000n, 1000), 1000);
  assert.equal(remainingSeconds(900n, 1000), 0);
});

test('formatDuration 三种形态', () => {
  assert.equal(formatDuration(0), '已结束');
  assert.equal(formatDuration(59), '00:59');
  assert.equal(formatDuration(61), '01:01');
  assert.equal(formatDuration(3661), '1:01:01');
});

test('shortAddr 截断保留首尾', () => {
  assert.equal(shortAddr('0xf39Fd6e51aad88F6F4ce6aB8827279cffFb92266'), '0xf39F…2266');
});
```

- [ ] **Step 2: 运行测试确认失败**

Run: `node --test demo/lib.test.mjs`
Expected: FAIL，报 `Cannot find module './lib.mjs'`

- [ ] **Step 3: 实现 `demo/lib.mjs`**

导出上述 5 个函数。`parseUsdTo8` 用 `/^\d+(\.\d{1,2})?$/` 校验后按 `整数部分 * 10n**8n + 补零的小数部分` 计算，**不要**用 `Number` 做浮点乘法。

- [ ] **Step 4: 运行测试确认通过**

Run: `node --test demo/lib.test.mjs`
Expected: `# pass 6`

- [ ] **Step 5: 提交**

```bash
git add demo/lib.mjs demo/lib.test.mjs
git commit -m "feat(demo): 演示页纯计算库与单测"
```
